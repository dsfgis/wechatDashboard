# 待办管理、项目归属、日程概览与桌面日历验证清单

## 1. 使用规则

- 所有检查项初始均为未完成。只有实际执行验证、确认观察结果并填写可复核证据后，才能勾选。
- `tasks.md` 描述要做的工作；本文件描述证明结果正确所需的证据。任务完成不自动等于检查通过。
- 自动化验证使用仓库控制台回归运行器；`dotnet test` 不能作为测试已执行的证据。
- 编译成功不能替代 SQLite 数据核对、失败路径、并发、WPF 实际点击、应用重启或回滚验证。
- 工作区可能存在无关未提交修改。证据必须能区分本功能改动，且不得通过 reset、checkout 或批量覆盖制造“干净”状态。
- 证据不得包含真实消息正文、数据库密钥、账号凭据或不必要的待办描述。
- 任一检查发现需求或设计存在实质偏差时，停止实现，修订受影响的四份 SDD 文档并重新取得整体确认。
- CHECK-005 至 CHECK-049 保留 v3/v4 分组及既有日历能力的历史验证记录；其中尚未完成且只验证旧分组交互的步骤，由 CHECK-050 至 CHECK-058 取代，不得再作为目标产品行为执行。既有非分组回归证据仍须保留并在完整回归中复验。
