- 诊断结论：`UpdateTodoAsync` 写 status / 清 completed_at 正常，`TodoWorkbenchViewModel.RefreshAsync()` 也会把行移回活动分组；**唯一缺陷是日历未刷新**——详情回调只刷工作台，`DesktopCalendarViewModel`（日程概览与桌面日历共用实例）缓存未更新。`MainWindow.RefreshAsync()` 只刷当前 Tab，不能代替全局刷新。
